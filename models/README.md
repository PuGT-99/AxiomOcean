# AxiomOcean FP32 ONNX Models

The pretrained FP32 ONNX models are distributed via GitHub Releases.

Download the 1-day and 5-day model archives from:
https://github.com/PuGT-99/AxiomOcean/releases

Extract all model files into this directory.

Both models are required for the 10-day hybrid forecast.

Each .onnx file must be placed alongside its corresponding
.onnx.data file.
